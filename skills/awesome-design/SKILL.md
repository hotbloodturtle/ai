# Awesome Design references

The independent shared checkout is `~/.local/share/ai-tools/awesome-design-md`.
If missing, clone https://github.com/VoltAgent/awesome-design-md there.
Search its `design-md/` folder for the requested reference; list actual directories instead of assuming a fixed site count.
Read the selected DESIGN.md and apply its typography, spacing, colors, and layout to the requested interface. Preserve the product's content and existing implementation constraints.
When the user wants a project-owned design contract, copy the chosen reference to the project's DESIGN.md after checking for an existing file, and record the source.
This collection provides design references; it does not implement the app. Hallmark can complement the reference when available and appropriate.
